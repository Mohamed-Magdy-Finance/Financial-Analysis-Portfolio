## Project Description
The system is built to function as a digital accountant, eliminating the need for manual posting. By integrating advanced formulas and dynamic references, a single entry in the General Journal automatically updates the General Ledger, Trial Balance, and final Financial Reports.

## Core Features
* **Full Cycle Automation:** Seamless synchronization from Journal entries to Financial Statements.
* **Smart Chart of Accounts (COA):** Structured coding for assets, liabilities, equity, revenues, and expenses.
* **Trial Balance Validation:** Built-in control checks to identify and prevent entry imbalances.
* **Dynamic Reporting:** Automatically generated Income Statement, Balance Sheet, and Owner's Equity reports.

## Navigation Guide
1. **Home Page:** Start here for a visual guide of the entire accounting process.
2. **General Journal:** Enter your daily transactions with their respective account codes.
3. **T-Accounts & Trial Balance:** Monitor the movement and verify the accuracy of each account.
4. **Financial Statements:** View the final outputs automatically generated by the system.
