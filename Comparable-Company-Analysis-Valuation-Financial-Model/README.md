#  Comparable Company Analysis (CCA) Model

A specialized valuation model used to estimate the fair value of a company by comparing it to similar peer groups in the industry. This model utilizes key market multiples to provide a comprehensive relative valuation.

---

##  Model Architecture
The model **Comparable-Company-Analysis_vF.xlsx** performs a relative valuation by benchmarking a "Target Company" against industry peers using Enterprise Value (TEV) and Equity Value metrics.

### Key Metrics Tracked:
* **Market Capitalization:** Calculation of equity value for all peer companies.
* **Enterprise Value (TEV):** Adjusting market cap for debt and cash to see the total operational value.
* **LTM Financial Metrics:** Analysis of Last Twelve Months (LTM) Revenue, EBITDA, EBIT, and Net Income.

---

##  Valuation Multiples Included:
The model automatically calculates and compares the following industry-standard multiples:
* **TEV / Revenue:** Measuring valuation relative to sales.
* **TEV / EBITDA:** The primary multiple for assessing operational profitability.
* **TEV / EBIT:** Providing insight into profitability after depreciation.
* **P/E Ratio:** Price-to-Earnings multiple for equity-side valuation.
